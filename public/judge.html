🦺 safeU — Judge's Verification Guide

Korean workplace-safety compliance where the human-in-the-loop isn't UX philosophy — it's statute. This page lets you verify every claim in about 3 minutes, no Korean required.

Why this domain forces human–agent collaboration: Korea's amended Occupational Safety and Health Act (산업안전보건법, in force 2026-06-01) makes workplace risk assessment fineable up to ₩10,000,000 — and separately fines excluding workers from participation and not sharing results (up to ₩5,000,000 each, Art. 36). The law itself says an AI cannot finish this document alone. safeU's WebMCP tool surface is shaped exactly like that law: everything a manager may delegate is a tool; everything the statute reserves for humans has no tool at all.

3-minute test itinerary

Setup (choose one):

  • ChatGPT desktop app — open safeu.netlify.app in the built-in browser (site tools work out of the box; personal accounts, GPT-5.6 Sol/Terra).
  • Chrome 149+ — enable chrome://flags/#enable-webmcp-testing, open the site, and drive tools with any WebMCP agent surface (e.g. the Model Context Tool Inspector extension).

The header badge shows the live tool count. Then:

  1. Ask: I run a 12-person metal fabrication shop in Korea — what safety paperwork do I legally need? → the agent calls set_workplace_profile; the Step-1 dashboard rebuilds live with 10 duties, each carrying a statute chip and the real fine amount.
  2. Ask: Draft a risk assessment for our welding and press work. → rows slide into Step 2 with amber "Agent draft" badges. (Or attach any risk-assessment file — HWP/PDF/Excel/photo — and say "put this into safeU".)
  3. Ask: Are we ready for a labor-office inspection? → check_inspection_readiness returns blockers labeled 👤 human-only vs 🤖 agent-fixable. The agent can fix its own; it must ask you to confirm rows, record worker participation, and sign.
  4. Click Confirm on the rows (Step 2), fill participation + signature (Step 3) → watch the toast: the three assessment write tools unregister (a toolchange event — the document is sealed). Ask the agent to add a row now; it can't — but it can still prepare a TBM briefing from the sealed, confirmed rows.
  5. Step 4 → Print: a 6-document Korean inspection pack (assessment in the government-standard layout with signature lines, worker-participation minutes, result-sharing confirmation, postable summary, TBM briefing log, Serious-Accidents-Act semiannual check sheet).

Falsifiable claims — try to break them

1. "Sign the document for me." — No signing tool exists. Signatures, worker participation, duty check-offs and printing are absent from every inputSchema. Enforcement by absence, not validation.
2. Ask the agent to modify a row a human has Confirmed. — Refused: the tool returns row_confirmed_by_human and instructs the agent to ask you to unlock it.
3. Ask the agent to prepare a TBM briefing before any row is confirmed. — Refused: a toolbox meeting may only brief workers on human-confirmed hazards.
4. Complete review & sign, then run getTools() (or check the tool list in your agent surface). — The write tools are gone; unlock one row and they re-register. In any browser console: window.__safeuActiveTools.
5. Every duty card and regulation result cites its statute with a law.go.kr source link — Korean statutes carry no copyright (Copyright Act Art. 7), and the bundled texts were verified against the current amendments (Aug 2026).
